Jupyter Notebooks AI/ML and STEM Learning

Learning STEM, one cell at a time

Jupyter notebooks bring live code, visualization, and narrative together in a single document. We build notebooks that help students explore materials science, mechanical engineering, chemistry, and computer science and many more topics through hands on computation instead of static slides.

Why Jupyter notebooks for STEM

The University of Florida is developing python Jupyter notebooks that bridge the gap between STEM domain knowledge and concepts in artificial intelligence. These notebooks will be used in multiple undergraduate courses to showcase how computational methods and AI are used within domain disciplines. The notebooks are designed to be interactive experiences that guide students through theoretical background concepts, and into real world data applications and computational methods that are integrated by design and reflect real workforce practices. These notebooks are being piloted at UF with the goal of broader adoption across universities in both the US, as well as globally.

Learn by doing

Students change a parameter and immediately see how a stress curve, a gas mixing simulation, or a convolutional neural network responds.

Theory next to code

Markdown cells give detailed explanations and equation derivations while the code cell right below it carries out the calculation, so nothing is left abstract.

Built by experts

Every notebook here was written and/or reviewed by a team of experts and tailored for instructors teaching STEM topic in real courses.

Easy setup

Every notebook automaticly installs libraries necesary to run the notebook. No installation is required to get started.
