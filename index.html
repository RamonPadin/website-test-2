NotebookLab STEM Learning

Learning STEM, one cell at a time

Jupyter notebooks bring live code, visualization, and narrative together in a single document. We collect and build notebooks that help students explore mechanical engineering, chemistry, and materials science through hands on computation instead of static slides.

Why notebooks for STEM

A single environment for equations, code, and results

Learn by doing

Students change a parameter and immediately see how a stress curve, a titration result, or a stress strain plot responds.

Theory next to code

Markdown cells hold the derivation while the code cell right below it carries out the calculation, so nothing is left abstract.

Built by instructors

Every notebook here was written or reviewed by an instructor teaching that exact topic in a real course.

Runs anywhere

Open a notebook locally, on JupyterHub, or in a free cloud environment. No installation is required to get started.
